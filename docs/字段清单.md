# 字段清单（A 给 B / C 的接口约定）

> 目的：W2 要冻结 schema，冻结后只加字段、不改已有字段。这份清单在 W1 内定死，避免 W2 全组返工。
> 状态：**草案，W1 末确认后冻结**。

## 一、chunk（课件文本块）—— B 建表，A 提供切块规则

| 字段 | 类型 | 说明 | 谁填 |
|---|---|---|---|
| `chunk_id` | INTEGER PK | 全局唯一，自增 | B |
| `course` | TEXT | 章名，直接取文件名，如"第3章" | B |
| `slide_no` | INTEGER | 页码（PPT 第几页，从 1 开始） | B |
| `raw_text` | TEXT | 原始中文正文（标题+正文+表格+备注拼接） | B |
| `tokenized` | TEXT | jieba 切词后空格拼接，**只有它能进 FTS5** | A |
| `title` | TEXT | 该页第一行（标题行），用于加权 | B |

切块规则（A 定）：**一页一块**；正文少于 10 字的页跳过（封面、纯图片页）；表格按 `a | b | c` 拼成一行；备注拼在正文末尾加前缀"备注："。

当前实测：5 份课件 → 265 块，跳过 20 页纯图片页。

## 二、FTS5 虚表 `chunks_fts` —— B 建，A 灌

| 字段 | 索引 | 说明 |
|---|---|---|
| `chunk_id` | UNINDEXED | 关联 chunk 表 |
| `course` | 索引 | 中文分词后写入 |
| `page` | UNINDEXED | 页码 |
| `body` | 索引 | `tokenized` 内容 |
| `raw` | UNINDEXED | 原文，用于回显 |

排序用 `bm25(chunks_fts)`，分数为负，越小越相关。

## 三、检索结果契约 —— A 提供，B / C 消费

`from retrieval.search import search`

```python
search(conn, query: str, top_k: int = 3) -> list[dict]
```

返回每一项：

| 键 | 类型 | 说明 |
|---|---|---|
| `chunk_id` | int | 唯一标识，用于跳转和高亮 |
| `course` | str | 章名，如"第3章" |
| `page` | int | 页码，前端"第 3 章第 18 页"就靠这两个字段 |
| `text` | str | 原文片段，前端展示 |
| `score` | float | bm25 分数，负数，仅用于调试和阈值判断 |

约定：
- **函数不 print、不抛业务异常**，无结果返回空列表
- 改进版 `search_improved` 返回结构完全一致，可直接替换
- 不用返回分词结果，前端和模型都不需要

## 四、turn（追问轮次）—— B 建，A 在 W3 写入

| 字段 | 类型 | 说明 |
|---|---|---|
| `turn_id` | INTEGER PK | 自增 |
| `session_id` | TEXT | 会话标识 |
| `round_no` | INTEGER | 第几轮，1/2/3 |
| `chunk_id` | INTEGER | 本轮依据的块；拒答时为 NULL |
| `question` | TEXT | 本轮追问句 |
| `user_answer` | TEXT | 用户作答原文 |
| `diagnosis` | TEXT | 命中 / 部分 / 偏离 / 未答 |

没有这张表就算不出"先答率""平均轮次""放弃率"三个指标，W4 的对照实验也做不了。
