# AI 学习助手前端 W1 原型

## 本周实现
- 输入框：输入《计算机程序设计》相关问题
- 提问按钮：点击后触发前端事件
- 回答区：使用本地模拟数据显示回答
- 示例问题：点击后自动填入输入框
- 空输入校验与按钮状态反馈

## 运行方式
无需安装依赖。直接用浏览器打开 `index.html` 即可。

也可以在项目根目录运行：
```bash
python -m http.server 8000
```
然后访问 http://localhost:8000/src/frontend/ （将文件放入该目录后）。

## 说明
当前是 W1 前端原型，不连接后端、不调用大模型。引用页码明确标记为待接入教材检索后显示，不伪造教材出处。
